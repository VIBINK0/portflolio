## 🚀 Running Locally

To serve the portfolio locally, you can use any static HTTP server:

```bash
# Using Python 3
python3 -m http.server 4321

# Or using Node.js / npx
npx serve .
```

Then open [http://localhost:4321](http://localhost:4321) in your browser.
